# Project Memory Format

Use this format when writing a project-level memory skill.

## File layout

`.codex/skills/project-memory/SKILL.md`

Optional:

- `.codex/skills/project-memory/references/memory.md`
- `.codex/skills/project-memory/references/decisions.md`

## Minimal sections

- Project goal
- Current architecture
- Stable conventions
- Important decisions
- Known issues
- Open follow-ups
- Safe cleanup notes

## Writing rules

- Keep entries short and factual.
- Prefer bullets over prose.
- Write only durable information.
- Update the existing memory skill instead of creating duplicate copies.
